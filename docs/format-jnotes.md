# Jnotes `.Jnotes` 格式记录

以下记录描述了在 **Jideos 云记 3.2.3.2** 中观察到的结构。

## 外层容器

一个 `.Jnotes` 文件是 ZIP 压缩包。已观察到的导出文件使用以下两个名称之一作为主要数据入口：

```text
zip.Jzip
zip.Jnotes
```

这两个名称不是两种内层协议版本。它们都包含相同的 TRY v2 顺序记录流，区别只在于外层 ZIP 的数据入口名称。转换器会按名称精确选择唯一入口；如果两个入口同时存在、同名入口重复，或两个入口都不存在，会停止并报告错误，避免误读文件。

入口所在的 ZIP 也可以包含其他辅助成员；转换器只读取选中的数据入口。ZIP 成员的 CRC 校验失败时，文件会被视为损坏。

选中的入口是一种自定义顺序容器。数据以 Java 风格的 UTF 字符串开始：

```text
TRY
```

后面跟着内层协议版本整数和笔记 UUID。目前支持的内层协议版本是 `2`。因此，`zip.Jzip` / `zip.Jnotes` 是容器名称，`TRY` 后的整数才是当前记录流版本；不能用入口名称推断协议版本。

随后按顺序存储记录。测试笔记包含的记录族包括：

- `NOTE`
- `PAGE`
- `STROKE`
- `IMAGE`
- `TEXT`
- `PDF`
- `COVER`
- `AUDIO_EX`

每条记录以大端序 `int32` 标记 `1` 开始，并依次包含记录类型、来源、对象 ID、负载长度、父对象 ID、辅助路径、辅助长度、负载和可选二进制数据。容器末尾包含一个短尾部；当前样本的尾部为 `int64(2)`、UTF 字符串 `Lucky` 和 `int64(19)`。早期样本还观察到 `int32(0) + Lucky` 的兼容尾部。

记录流解析规则是：遇到非 `1` 标记后，将其余字节视为尾部；如果已经读到记录标记 `1`，但该记录的字段或负载不完整，则视为损坏并失败，不会静默丢弃后续记录。

## 手写内容

笔迹负载是明文 JSON。嵌套 `c` 对象中的重要字段包括：

| 字段 | 含义 |
|---|---|
| `a` | 工具/对象类型 |
| `c` | 有符号 ARGB 颜色整数 |
| `d` | 类似宽度的内部值 |
| `k[]` | 采样后的最终路径 |

测试格式中的 `k[]` 每个点至少包含 x/y 和类似压力的数据。

## PDF 页面

PDF 笔记通常包含一个 `PDF` 记录以及多个 `PAGE` 记录：

- `PDF.payload` 是完整的原始 PDF 字节；
- `PDF.object_id` 是 PDF 文件名；
- `PAGE.e` 指向该 PDF 文件；
- `PAGE.c` 是 PDF 的从零开始页面索引；
- `PAGE.k` 和 `PAGE.l` 保存当前页面的宽度和高度。

页面上的 `STROKE`、`IMAGE` 和 `TEXT` 记录仍通过 `PAGE.a` 页面 UUID 作为覆盖层保存。`PDF` 内容不应被当作封面图片或普通页面图片处理。

### 受控样本中确认的类型映射

| Jnotes `a` | 含义 |
|---:|---|
| 1 | 圆珠笔 |
| 2 | 钢笔 |
| 3 | 荧光笔 |
| 5 | 铅笔 |
| 6 | 手写识别/规则化后的几何图形 |
| 7 | 显式几何工具对象 |
| 10 | 纸胶带 |

## type 6 几何图形

受控样本确认：

- `a=6, b=0`：手写内容被规则化为直线；
- `a=6, b=12`：手写内容被规则化为曲线。

经过完整验证的大型笔记还包含 `a=6, b=4`，v1.0.0 将其视为类似椭圆/圆的识别图形。

`l[]` 可以保存少量定义点/控制点，而 `k[]` 保存最终规则化后的显示路径。

## type 7 几何图形

一个受控的几何工具页面确认，`a=7` 表示显式几何工具对象，`b` 用于选择子类型。观察到的 Jnotes 子类型包括：

| `b` | 观察到的图形 |
|---:|---|
| 0 | 实线 |
| 1 | 虚线 |
| 3 | 矩形 |
| 4 | 圆/椭圆 |
| 5 | 三角形 |
| 6 | 直角三角形 |
| 11 | 波浪线 |
| 13 | 单向箭头 |
| 14 | 双向箭头 |
| 15 | 六边形 |
| 16 | 五角星 |
| 17 | 圆柱体 |
| 18 | 三棱柱 |
| 19 | 立方体 |

v1.0.0 只为经过设备验证的笔记中实际出现的子类型提供华为原生映射。其他子类型会回退为可编辑的笔迹路径。

## 纸胶带

观察到的 `a=10` 对象具有独立的路径和样式字段。重要观察包括：

- 类似宽度的字段 `d`；
- 颜色字段 `c`；
- 样式选择器 `y`；
- 不透明/轮廓模式选择器 `z`；
- 位于 `k[]` 中的路径。

尚未确认华为原生等价物。v1.0.0 会跳过纸胶带，而不会假装把它当作普通笔迹。

## 图片和贴纸

Jnotes 图片记录可以携带原始 PNG/JPEG 字节。受控贴纸样本是普通的 RGBA PNG 图片，可以自然映射到华为图片元素。

## 音频

观察到 `AUDIO_EX` 记录包含原始 MP3 数据，以及文件名、时长和页面几何信息等元数据。该格式已为未来工作记录，但 v1.0.0 不会启用音频转换。
