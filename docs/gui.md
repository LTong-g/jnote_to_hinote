# 图形界面使用说明

## 启动

安装项目后，在项目环境中运行：

```powershell
jnotes2hinote-gui
```

也可以运行：

```powershell
python -m jnotes2hinote.gui
```

图形界面默认使用简体中文，也可以在窗口右上角切换为 English。

## 添加输入

输入区域支持三种来源：

- **文件**：选择一个或多个 `.Jnotes`/`.jnote` 文件；
- **文件夹**：默认只扫描文件夹的直接子级；
- **TXT 清单**：每行一个文件或文件夹路径。

TXT 清单中的空行和以 `#` 开头的行会被忽略。相对路径以 TXT 清单所在目录为基准。输入来源可以混合添加，相同文件只会转换一次。

勾选“包含子目录中的文件”后，文件夹和清单中的文件夹会递归搜索所有子目录。

## 输出设置

输出目录用于保存批量生成的 `.hinote` 文件。文件重名时可以选择：

- **自动添加序号**：生成 `note.hinote`、`note_2.hinote` 等文件；
- **跳过已有文件**：不覆盖已经存在的文件；
- **覆盖已有文件**：覆盖已有文件，但同一批次中的重名输入仍会自动加序号。

“转换页数”填 `0` 表示转换全部页面；填入正整数可以只转换前几页，用于先做小范围检查。

启用 JSON 报告后，默认写入输出目录中的 `conversion_report.json`。报告会记录成功、失败、跳过的文件和转换结果。

## 转换过程

点击“开始转换”后，程序会先扫描输入来源并显示发现的文件数量。如果有路径不存在、无法读取或目录为空，程序会列出问题，并询问是否继续处理其他可用文件。

转换在后台运行，窗口不会因为单个文件耗时较长而失去响应。结果表和日志会实时显示：

- 当前处理的文件；
- 成功生成的输出文件；
- 失败或跳过的文件及原因；
- 总体进度。

单个文件失败不会阻止其他文件继续转换。

点击“停止”后，程序会在当前文件完成后停止，不会删除已经生成的输出文件。

## 设置记忆

程序会记住以下界面设置：

- 最近使用的输出目录；
- 是否递归搜索；
- 页数限制；
- 报告设置；
- 文件重名策略；
- 界面语言；
- 窗口大小。

设置保存在用户配置目录中，不会写入项目目录，也不会上传任何笔记内容。

## Windows 打包

安装打包依赖后，可以生成无控制台窗口的 Windows 程序目录：

```powershell
./scripts/build_windows.ps1
```

生成的程序位于 `dist/Jnotes2Hinote/Jnotes2Hinote.exe`。请保留 `dist/Jnotes2Hinote` 目录中的运行库文件；打包程序使用当前的 v1.1.2 转换核心。
