- 171 页
- 44,828 条手写/几何笔迹
- 48 张图片/贴纸

- 245 条 Jnotes type 6/type 7 几何记录

- 最终大型验证笔记中没有音频

- 171 个输出页面

- 48 张图片

  - `base5`：9 页
