# v1.1.2 修复验证摘要

## 修复范围

v1.1.2 是 v1.1.1 的兼容性修复版本，保留 v1.1.1 的 `.hinote` 文件结构、笔迹映射和几何图形规则。

本版本新增 `converter_v1_1_2.py`，不修改历史文件 `converter_v1_1_1.py`。生成缩略图时，转换器会优先使用计算机中支持中文和英文的系统字体；如果系统没有可用字体，也会安全回退，不再因 Pillow 默认字体的字符集限制而中断转换。
