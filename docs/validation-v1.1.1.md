## 本版本变更

v1.1.1 只调整普通不透明 Jnotes type 6/type 7 几何图形的宽度处理。几何宽度改为与普通笔迹相同的直接映射：

```text
Huawei style+84 = Jnotes d
```

转换器不会对该值进行除法、乘法、固定档位量化、四舍五入或额外缩放，小数宽度会被保留。

经过设备验证的半透明 `type=6, b=12` 荧光笔生成曲线规则保持不变。
