# v1.2.0 PDF 转换验证摘要

## 目标

v1.2.0 修复 PDF-backed Jnotes 转换后页面为空白的问题。PDF 页面以原始 PDF 附件形式写入 Hinote，由每个页面引用 PDF 页码；正文不转换为图片。

## 自动化验证

- PDF 记录以 `%PDF-` 开头并可由纯 Python PDF 解析器读取。
- 输出 PDF 字节与输入 PDF 完全一致。
- 顶层笔记包含 `attachType=3` PDF 附件。
- 每个 PDF 页面均设置正确的 `bkgAttachmentId` 和 `bkgAttachmentIndex`。
- PDF 页面可以同时包含页面级 PENCILENGINE 笔迹附件。
- Jnotes `COVER` 不再作为全页图片，仅用于第一页缩略图。
- 输出归档在发布前重新打开并检查 PDF 文件、附件、页面引用和 SHA-256 元数据。
- 页面使用各自的 `PAGE.k / PAGE.l` 比例。
