# 限制

以下限制适用于当前 v1.1.1 实现，除非另有说明。

- **纸胶带（`type=10`）：** 尚未确认华为原生等价物，目前会跳过。
- **音频：** 已逆向确认 Jnotes `AUDIO_EX` 和华为通用附件存储，但尚未启用音频转换。
- **排版：** 文本框保持可编辑，但字体度量、换行和行距可能无法像素级一致。
- **普通笔宽等效性：** 尚未针对所有笔族和界面宽度完成完整标定。
- **几何宽度映射：** 支持的普通不透明 type 6/type 7 几何图形使用与普通笔迹相同的 Jnotes `d` 直接值，不进行固定档位转换或算术缩放。
- **半透明 type 6/subtype 12：** 在经过验证的云记 3.2.3.2 笔记中，这些对象由荧光笔内容生成平滑曲线。v1.1.1 会将其映射为华为原生荧光笔笔迹并保留源透明度；其中 `d=30 → 源荧光笔 d=6 → 华为宽度=32` 的关系只对该设备验证样本成立。
- **版本兼容性：** 当前只有云记 3.2.3.2 → 华为笔记 15.0.14.295 经过设备验证。

导入转换后的笔记前，请始终保留原始 `.Jnotes` 文件。
