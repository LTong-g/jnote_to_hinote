# 限制

以下限制适用于当前 v1.5.2 实现，除非另有说明。

- **PDF 笔记：** 当前支持将单个或多个未加密 PDF 原样保存为 Hinote 顶层附件，并通过页面索引引用；多个 PDF 混合页面以及加密 PDF 尚未完成设备验证。
- **PDF 缩略图：** 每个 PDF 背景页都会生成基于原始 PDF 和可编辑覆盖层的 JPEG 缩略图。加密、损坏或当前 PDFium 无法渲染的 PDF 会使转换失败；该行为尚待设备端导入复测。

- **纸胶带（`type=10`）：** 尚未确认华为原生等价物，目前会跳过。
- **音频：** 已逆向确认 Jnotes `AUDIO_EX` 和华为通用附件存储，但尚未启用音频转换。
- **排版：** 文本框保持可编辑，但字体度量、换行和行距可能无法像素级一致。
- **普通笔宽等效性：** 尚未针对所有笔族和界面宽度完成完整标定。
- **几何宽度映射：** 支持的普通不透明 type 6/type 7 几何图形使用与普通笔迹相同的 Jnotes `d` 直接值，不进行固定档位转换或算术缩放。
- **半透明 type 6/subtype 12：** 在经过验证的云记 3.2.3.2 笔记中，这些对象由荧光笔内容生成平滑曲线。v1.1.2 继续沿用 v1.1.1 的映射，将其写为华为原生荧光笔笔迹并保留源透明度；其中 `d=30 → 源荧光笔 d=6 → 华为宽度=32` 的关系只对该设备验证样本成立。
- **版本兼容性：** 当前只有云记 3.2.3.2 → 华为笔记 15.0.14.295 经过设备验证。
- **Jnotes 容器：** 已兼容已观察到的 `zip.Jzip` 和 `zip.Jnotes` 两种外层 ZIP 数据入口名；其他入口名或同时包含两个入口的文件会被拒绝。两种入口的兼容性已完成自动化验证，尚未分别完成设备复测。
- **缺少 PDF 数据：** 如果页面引用了 PDF 文件名，但笔记中没有对应的 `PDF` 记录，转换会失败；入口名称兼容不会替代缺失的 PDF 数据。

导入转换后的笔记前，请始终保留原始 `.Jnotes` 文件。
