# 版本化转换核心

## 冻结的 v1.0.0 核心

旧版基于参考文件、经过设备验证的转换核心是：

`src/jnotes2hinote/converter_v1_0_0.py`

SHA-256：

`5e8422ac8f6c05d6ced734e9c6a50095ff56719cf32de3237b41e21d0d98aee6`

该文件作为当前公开的 v1.0.0 历史核心，不再进行源码整理或行为调整。后续转换行为应放入新的版本化核心；`CORE_SHA256.txt` 记录其当前哈希。

## 历史 v1.1.0 核心

`src/jnotes2hinote/converter_v1_1_0.py`

该核心引入了自包含的华为 PENCILENGINE 生成逻辑，并作为历史 v1.1.0 实现保留。

## 历史 v1.1.1 核心

`src/jnotes2hinote/converter_v1_1_1.py`

v1.1.1 保留自包含架构，并修正普通不透明几何图形的宽度映射。该文件作为历史版本保留，不再修改。后续行为变化应新增版本化核心，不要重写历史核心。

## 历史 v1.1.2 核心

`src/jnotes2hinote/converter_v1_1_2.py`

v1.1.2 复用 v1.1.1 已验证的底层格式和映射逻辑，仅修复缩略图中文文本的系统字体处理。项目发行版 v1.3.1 使用该核心。

项目发行版 v1.3.1 在该核心之上提供命令行批量输入和桌面图形界面，并修复缩略图中文文本的字体兼容性。

## 历史 v1.2.0 核心

`src/jnotes2hinote/converter_v1_2_0.py`

v1.2.0 在 v1.1.2 的笔迹、图片、文本和几何转换基础上增加原生 PDF 附件支持。它保留源 PDF 字节，并通过 Hinote 页面背景附件引用 PDF 页面，不将 PDF 正文栅格化为图片。该文件作为历史版本保留，不再修改。

## 历史 v1.5.1 核心

`src/jnotes2hinote/converter_v1_5_1.py`

v1.5.1 保留 v1.2.0 的 Hinote 输出和原生 PDF 处理，仅新增对 `zip.Jzip` / `zip.Jnotes` 两种外层数据入口的兼容，并将普通笔记和 PDF 笔记统一到同一个版本化读取器。该文件作为历史版本保留，不再修改。

## 历史 v1.5.2 核心

`src/jnotes2hinote/converter_v1_5_2.py`

v1.5.2 先调用已冻结的 v1.5.1 核心生成可编辑 Hinote 内容，再在封包阶段重建每页缩略图：普通页按页面对象绘制，PDF 背景页使用其原始 PDF 页面并叠加可编辑对象。该核心不改写 v1.5.1 的页面、附件或笔迹映射。

## 当前 v1.5.3 核心

`src/jnotes2hinote/converter_v1_5_3.py`

v1.5.3 保留 v1.5.2 的清晰缩略图和可编辑内容，将缩略图尺寸限制改为最长边 1080 像素，并按 Hinote 引用顺序写入顶层 PDF/outline、页面资源和校验清单。项目发行版 v1.5.3 使用该核心。

从项目 v1.5.1 起，转换核心采用发生修改时的项目版本号：某个项目版本修改了核心，就新增同版本号的版本化核心；未修改核心的项目版本继续引用最近一次核心版本。已发布的历史核心保持冻结，不重写源码。
