# 映射规则

## v1.1.0 实现说明

### 普通笔型映射

| Jnotes 类型 | 华为 `pen_type` |
|---:|---:|
| 1 圆珠笔 | 2 |
| 2 钢笔 | 1 |
| 3 荧光笔 | 5 |
| 5 铅笔 | 3（HB） |

### 荧光笔

普通 Jnotes type 3 荧光笔笔迹使用：

```text
华为宽度 = Jnotes d × 16 / 3
```

样式偏移 `+76` 和 `+80` 的两个华为透明度字段都会写入。标准标定上限为 `80/255`，如果源透明度更低则取源透明度。

### 几何图形

支持的透明 type 6/type 7 几何图形使用华为原生图形样式 PENCILENGINE 记录。

| Jnotes | 含义 | 华为图形代码 |
|---|---|---:|
| type 6, b=0 | 规则化直线 | 0 |
| type 6, b=12 | 规则化平滑曲线 | 16 |
| type 6, b=4 | 识别出的椭圆 | 10 |
| type 7, b=3 | 显式矩形 | 7 |
| type 7, b=4 | 显式圆/椭圆 | 10 |

经过设备验证的几何宽度档位：

```text
Jnotes d < 4  -> 华为宽度 2
Jnotes d < 8  -> 华为宽度 4
其他          -> 华为宽度 8
```

早期 v1.0.0 的 `Jnotes d / 3` 几何规则已经弃用，因为设备测试显示它会造成视觉回归。

### 荧光笔生成的平滑曲线

半透明的 Jnotes `type=6, b=12` 单独处理。在验证笔记中，这些记录由荧光笔手写内容平滑生成。v1.1.0 将其写成华为原生荧光笔笔迹，而不是原生几何图形，并保留源透明度。设备验证样本使用 `d=30`，对应源荧光笔 `d=6`，因此华为宽度为 `32`。

### 纸张背景

| 华为模板 | 含义 |
|---|---|
| `base1` | 空白 |
| `base4` | 宽横线 |
| `base5` | 窄横线 |
| `base6` | 点阵 |
| `base3` | 窄/小方格 |
| `base2` | 宽/中方格 |

Jnotes 横线规则：界面尺寸 1–2 → `base5`；界面尺寸 3+ 及其他横线模板 → `base4`。

Jnotes 方格规则：界面尺寸 1–4 → `base3`；界面尺寸 5+ → `base2`。
