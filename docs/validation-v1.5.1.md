# v1.5.1 Jnotes 容器兼容性验证摘要

## 目标

v1.5.1 兼容两种已观察到的 Jnotes 外层 ZIP 数据入口：`zip.Jzip` 和 `zip.Jnotes`。两种文件的内层均为 TRY v2 顺序记录流，入口名称不应改变转换结果的格式或内容。

## 自动化验证

- 使用同一份 TRY v2 记录流分别放入 `zip.Jzip` 和 `zip.Jnotes`，解析出的 NOTE、PAGE、STROKE 等记录一致。
- 普通笔记的两种入口均可转换；普通笔记不会再次调用只支持 `zip.Jzip` 的历史解析器。
- PDF 笔记的 `zip.Jnotes` 入口可转换，源 PDF 字节保持不变，页面仍使用原生 PDF 附件和页码引用。
- 缺少入口、两个入口同时存在、入口重复、内层版本不支持和记录截断均会明确失败。
- ZIP CRC、TRY 魔数、内层版本、记录长度、关键 JSON 内容和 NOTE 页面尺寸会在读取阶段检查。
- 原有历史核心测试继续直接使用对应的历史模块；v1.0.0～v1.2.0 的版本化核心文件未修改。

## 版本范围

- 项目版本：v1.5.1
- 当前转换核心：v1.5.1
- 已测试源应用版本：云记 3.2.3.2
- 已测试目标应用版本：华为笔记 15.0.14.295
- Jnotes 内层记录流：TRY v2

两种入口的结构回归已完成。它们尚未分别完成华为设备复测；设备验证仍以兼容性记录中的版本组合为准。
