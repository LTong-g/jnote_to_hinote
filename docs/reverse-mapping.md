# 华为笔记转云记

Hinote2Jnotes 接受 `.hinote` 和 `.hjnote`，按 ZIP 内的笔记和页面元数据识别结构。
转换规则基于仓库中已观察到的华为笔记格式，未设置应用版本门槛。输出为包含
`zip.Jnotes` 的 TRY v2 压缩包。含多个笔记正文或没有可读取页面的文件会报错。

| 内容 | 转换规则 |
|---|---|
| 页面 | 按华为 `pageNumber` 排序，按页面比例和方向确定云记尺寸。输出画布的长短比例沿用源页，绝对尺寸采用规范值。 |
| 手写 | 支持圆珠笔、钢笔、荧光笔和 HB 铅笔。坐标按画布宽度反算，保留逐点压力和 BGR 颜色。普通笔宽直接映射，荧光笔宽度乘以 3/16 并使用渲染透明度。 |
| 图形 | 支持直线、曲线、矩形和椭圆。圆或椭圆统一写为云记显式几何对象 `a=7,b=4`。华为荧光笔统一写为普通云记荧光笔。 |
| 模板 | `base1` 空白、`base2` 宽方格、`base3` 小方格、`base4` 宽横线、`base5` 窄横线、`base6` 点阵。正向映射合并的档位选用一个已知的云记档位。 |
| 图片与文本 | 保留 PNG、JPEG、GIF 字节、图片位置和旋转，以及文本内容、位置、基础字号、颜色、粗体、斜体、下划线和对齐。图片和文本按层级排序，使用各自记录类型。 |
| PDF | 将未加密的原始 PDF 写入笔记，保留零起始索引及可编辑覆盖层。 |
| 封面 | 取首个有效页面的华为缩略图，缺少时尝试从页面内容生成预览。 |

未知笔型、图形、附件和页面对象会跳过。未知模板使用空白纸，加密、损坏或缺失
的 PDF 背景会跳过，页面上的已知覆盖层仍会转换。JSON 结果中的 `ignored`
按类型统计忽略项，`ignoredTotal` 为计数合计。

源码启动入口为 `python -m hinote2jnotes.gui`，CLI 为
`python -m hinote2jnotes`。Windows 构建使用
`./scripts/build_windows.ps1 -Tool Hinote2Jnotes`，生成
`dist/Hinote2Jnotes/Hinote2Jnotes.exe`。

自动化测试检查生成的记录、页序、可编辑对象、媒体字节和 PDF 页引用。
云记实机导入仍待验证。
