# v1.6.0 安全输出与批量报告验证

v1.6.0 沿用 v1.5.3 的 Hinote 内容、缩略图和封包行为，只增加输出路径保护、批量状态语义、CLI 错误处理和报告匿名化。

自动化检查覆盖：

- 没有扩展名或使用其他扩展名的单文件输出会追加 `.hinote`；
- 已有 `.hinote` 扩展名不重复追加，扩展名比较不区分大小写；
- 将源 `.Jnotes` 路径误作输出时生成旁路 `.Jnotes.hinote`，源文件字节保持不变；
- 转换失败、跳过、输入错误和取消后未执行数量分别统计；
- 部分成功的批量命令返回退出码 2；
- 默认转换错误不显示 Python traceback，`--debug` 保留诊断能力；
- 匿名化报告不包含笔记标题或完整本地路径；
- v1.5.3 及更早冻结核心的 SHA-256 保持不变。

这些改动不改变导入华为笔记后的页面内容。设备兼容性继续继承 v1.5.3 的状态，尚未因此新增设备验证声明。
