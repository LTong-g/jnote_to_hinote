# v1.5.2 缩略图验证

v1.5.2 的目标是修复 `.hinote` 导入后 PDF 页面缩略图空白，以及普通页面缩略图过低分辨率造成的模糊。

## 自动化验证

- 普通页面缩略图按 `pageRatio × 1080` 生成，JPEG 质量为 100，采样为 4:2:0。
- 普通页面的中文文本和单点笔迹会被绘制到缩略图中。
- PDF 多页笔记的每一页都会生成缩略图，且各页预览像素内容不同。
- PDF、普通页、PDF 的混排笔记会按页面的 `bkgAttachmentIndex` 选择正确 PDF 页；普通页不获得 PDF 背景引用。
- 每个缩略图都写入 ZIP `files/`、顶层 `fileList`、页面 `detailFileMap` 和 `custom_md.jhinote`，并验证 MD5 一致。
- PDF 笔记的页面 `cloudSyncState` 均为 `0`，与提供的原生 PDF `.hinote` 样本一致。

## 尚待实机验证

本版本已经完成本地自动化回归，但尚未在华为笔记 15.0.14.295 中重新导入验证。设备复测时应确认：

4. 打开和编辑页面后，笔迹、图片与文本仍保持可编辑。
